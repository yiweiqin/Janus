# TDB 算法贡献与可证伪性

本文将 TDB 主线拆成可独立检验的算法命题，避免把多个工程模块合并后作为单一创新。

## 命题 1：条件化最小披露的有限世界最优性

给定有限世界目录 `W`、披露单元 `F`、动作集合 `A`、非负披露成本和隐私预算 `δ`，对每个 `S⊆F` 按 `obs_S` 划分世界。若某一分区存在一个动作在所有世界中均满足安全契约且最坏遗憾不超过 `ε`，则该 `S` 可行。穷举所有子集并按成本、基数、字典序取最小者，返回全局成本最优解；不存在可行子集时返回 `UNKNOWN`。

这不是“披露越少越好”：可行性首先由跨世界决策稳定性和隐私约束决定，成本只在可行集合内进行最小化。该命题的适用范围是显式声明的有限模型，不能外推到未覆盖世界。

## 命题 2：保守干预排序的单调安全条件

对候选干预 `e`，若 `μ_e` 是 uplift 均值、`SE_e` 是标准误，且误差区间覆盖真实 uplift，则 `LCB(e)=μ_e-zSE_e` 是置信水平对应的保守收益界。将负迁移风险 `ρ_e` 和成本显式扣除后，只有 `Priority(e)>0` 的候选才进入建议集；其余候选转为 `UNKNOWN/NOOP`。该规则牺牲部分收益换取错误高置信动作率下降，必须用 risk-coverage 曲线验证。

## 命题 3：依赖集束的非加性交互

对双干预 `A,B`，定义：

```text
I(A,B)=U(AB)-U(A)-U(B)+U(∅)
```

`I≠0` 时，单一依赖边的边际收益不能解释联合结果；归因算法必须保留交互项或返回不可识别。该定义要求同一初始快照、同一 evaluator 和 paired noop，否则只能作为相关性指标。

## 必须报告的证伪实验

1. 与完整枚举 reference、随机披露、全披露和 set-cover 启发式比较；
2. 对 `ε`、`δ`、成本和世界覆盖率做敏感性分析；
3. 比较 LCB 排序与均值排序、固定启发式和 oracle 上界；
4. 人为构造 `I>0`、`I<0` 和 `I=0` 的双故障；
5. 在未见 task family、Agent-pair、relation type 和时间切分上重复上述实验；
6. 报告 family bootstrap 95% CI、效应量、risk-coverage、负迁移率和 abstain regret。

任何一项缺少独立 evaluator 或世界覆盖证明时，结论必须降级为 `UNKNOWN` 或 protocol-only。

## 命题 4：最小进化步骤的预算化选择

将候选干预集合记为 `S`，其可验证收益为 `g(S)`。当 `g` 被独立 evaluator 证明为单调子模函数时，在预算 `B` 下采用最大边际收益密度的贪心选择：

```text
e_t = argmax_e [g(S_t ∪ {e}) − g(S_t)] / Cost(e)
```

单位成本时，贪心解满足 `g(S_greedy) ≥ (1−1/e) g(S*)`；非单位成本时不自动宣称该界，必须提供额外近似证明或返回 `UNKNOWN`。这使“最小步骤优先级”成为预算化集合优化，而不是对单条边打分后顺序拼接。

对子模性进行随机三元组检验；一旦发现边际收益增加或非单调，撤销近似保证并降级为 `UNKNOWN`。

## 命题 5：自适应披露优于静态披露的策略类

静态方法选择一个固定集合 `S`。在双 Agent 协作中，字段的价值往往依赖已观测到的值，因此定义决策树策略 `π`：每个内部节点选择一个尚未披露的单元，每个叶节点输出鲁棒动作。参考目标为：

```text
min_π  E_prior[Cost(π,W)]
s.t.  max_w Regret(π,w) ≤ ε
      PrivacyLoss(π,w) ≤ δ
```

`solveAdaptiveDisclosure` 对声明有限世界和先验的模型做精确动态规划。叶节点使用区间效用的最坏遗憾 `max_a U_a - min U_{pi}`；区间重叠导致遗憾超过 `ε` 时不会猜测动作，而是继续披露或返回 `UNKNOWN`。静态最小集合是该策略类的特例，因此自适应策略的最优期望成本不会高于静态策略；这个不等式只在相同世界目录、先验、成本和约束下成立。

该结果把“何时继续 Probe、何时停止披露”纳入主算法，而不是把 Probe 当作额外工程步骤。

为避免先验错配，算法还支持有限先验集合 `\mathcal P` 的分布鲁棒版本：

```text
min_π max_{P∈𝒫} E_{W∼P}[Cost(π,W)]
```

所有先验共享同一个最坏遗憾和隐私约束。实现保留每个候选策略对每个先验的成本向量，只在根节点计算 `max_{P∈𝒫}`，并做 Pareto 支配剪枝；因此不会在不同子树中混用不同的“最坏先验”。单一先验是 `|𝒫|=1` 的特例；因此模型可以报告先验敏感性，而不是隐藏在一个未经验证的概率分布中。

**证明要点。** 任意静态集合 `S` 都可展开成一棵先披露 `S`、再在每个观测分支立即停止的策略树，因此属于 `π` 的可行子类。动态规划枚举所有可用单元和观测分区，在每个状态上取“立即停止”与“继续披露”的期望成本较小者，所以返回的策略不劣于该静态子类。该证明不声称对未知世界、错误先验或非矩形效用成立。

## 命题 6：披露价值的决策定义

字段 `f` 在当前信息状态 `I` 下的价值定义为：

```text
VOI(f|I) = [R(I) − R(I∪{f})] / [Cost(f) + λ_privacy PrivacyLoss(f)]
```

其中 `R` 是独立 solver 计算的最坏决策遗憾。该量把“为什么要披露这个字段”解释为决策歧义的减少，而不是注意力权重或相似度。非负成本、隐私损失和信息分区细化成立时，分子非负；若输入遗憾增加，则返回 `UNKNOWN`，防止把模型误差解释成负信息价值。

## 独立创新线：因果解释的部分识别

因果解释不再回归依赖分数，也不参与披露或进化优先级。给定干预响应向量 `y` 和原因签名矩阵 `A`，定义可识别集合：

```text
𝒞τ(y,A) = {S : ||A_S − y||∞ ≤ τ}
```

算法返回最小基数的 `S∈𝒞τ` 全部等价类：唯一集合时为 `IDENTIFIED`，多个集合时为 `PARTIALLY_IDENTIFIED`，为空时为 `UNIDENTIFIED`。这把“无法区分 Agent、交接和版本原因”作为正式的部分识别结果，而不是强行输出唯一归因。其实现为 `identifyCauseEquivalenceClass`，与 TDB 依赖数值、信息披露成本和进化优先级完全解耦。
